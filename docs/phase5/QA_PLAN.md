# Phase 5 QA plan

Validate with synchronized football footage and deterministic simulation captures.

- Touchline exits produce throw-ins for the team that did not touch last.
- Goal-line exits produce corners or goal kicks from last touch.
- Offside is recorded at the pass and penalized only when the candidate becomes involved.
- Advantage continues only while the fouled team retains a meaningful attack.
- Cards vary with foul severity, denying-opportunity context and referee profile.
- Penalty-area fouls create penalties at the correct mark.
- VAR freezes the authoritative ball, announces checking and resolves only reviewable decisions.
- Restarts place the ball, position both teams, respect countdowns and use selected routines.
- Match clock stops during VAR and restart setup; added time reflects stoppages.
- Tactical presets measurably alter line height, width, compactness and pressing.
- Low-end graphics preserve laws, controls and network state while simplifying presentation.
- Missing external assets always fall back safely without gameplay changes.
